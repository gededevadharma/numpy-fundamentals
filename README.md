# NumPy Fundamentals

Notebook belajar NumPy dari dasar sampai ufunc, dengan contoh kode yang
sudah dieksekusi semua tanpa error.

## Isi

- 70 sel (41 sel kode), 9 bab + penutup:
  1. Array Creation — Pembuatan Array
  2. Indexing on ndarrays — Pengindeksan
  3. I/O with NumPy — Simpan & Baca Data
  4. Data Types — Tipe Data
  5. Broadcasting — Penyiaran Operasi
  6. Copies and Views — Salinan vs Tampilan
  7. Working with Arrays of Strings and Bytes
  8. Structured Arrays — Array Terstruktur
  9. Universal Functions (ufunc) Basics — termasuk ufunc vs generalized
     ufunc, `frompyfunc`, `reduce`/`accumulate`/`reduceat`/`outer`/`at`,
     argumen `axis`/`dtype`/`out`, aturan type casting, array scalar,
     dan penanganan error floating-point.

## Cara pakai

1. Install Python 3 dan Jupyter (atau buka di VS Code dengan extension
   Jupyter).
2. Install NumPy:
   ```
   pip install numpy
   ```
3. Buka `NumPy_Fundamentals.ipynb` dan jalankan sel per sel dari atas
   ke bawah.

Notebook ini terakhir dieksekusi penuh tanpa error memakai NumPy 2.5.3.
